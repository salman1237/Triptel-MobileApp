# Triptel User App

React Native (Expo) consumer app for Triptel. Independent repo — own git history,
no backend code; talks to the existing Triptel `/api/v1` REST API.

**Start here: [`CLAUDE.md`](./CLAUDE.md).** It routes to everything else — stack,
rules, requirements, and how to pick up a session.

No app code exists yet. This repo currently holds the harness only:
`CLAUDE.md`, `docs/`, `feature_list.json`, `claude-progress.md`, `DECISIONS.md`,
`init.sh`, and `.claude/` (permissions, a destructive-command hook, two skills).
Run `init.sh` to produce the first runnable Expo app.
