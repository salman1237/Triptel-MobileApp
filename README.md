# Triptel User App

React Native (Expo) consumer app for Triptel. Independent repo — own git history,
no backend code; talks to the existing Triptel `/api/v1` REST API.

**Start here: [`AGENTS.md`](./AGENTS.md).** It routes to everything else — stack,
rules, requirements, and how to pick up a session. (`CLAUDE.md` is kept as a
one-line pointer to the same file, only because Claude Code looks for that
filename specifically.)

Status: see `claude-progress.md` for the current session log and
`feature_list.json` for exactly which features are `passing` vs. remaining —
don't trust this file to stay in sync with that count, it won't be updated
every session.
